# UltimateNotes

Modern Android notes client for **Nextcloud Notes**, with an Apple Notes–like experience. Offline-first, free software (GPL-3.0-or-later), built for F-Droid.

Cliente de notas moderno para Nextcloud Notes: carpetas, WYSIWYG sobre Markdown, checklists, favoritas, búsqueda offline, widget, bloqueo biométrico y exportación.

Sister apps: [UltimateTasks](https://github.com/qtekfun/UltimateTasks) · [UltimateDeck](https://github.com/qtekfun/UltimateDeck).

Docs: [`SPEC.md`](SPEC.md) · [`PLAN.md`](PLAN.md) · [`CLAUDE.md`](CLAUDE.md). No telemetry, no proprietary SDKs.
